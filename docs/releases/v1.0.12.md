# CellCounter v1.0.12 for macOS

This hotfix improves image previews and makes the first Cellpose model download visible, with clear errors when a connection stalls.

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized. See the [installation guide](../INSTALL.md).

## Image previews

- Single-frame 8-bit PNG, JPEG and BMP images prepare their selected source channel or RGB luminance natively, before Python starts. Scientific stacks, high-bit-depth data and other pixel layouts use the shared source reader.
- Analysis setup shows a bounded original preview while preparing the selected channel. Changing confidence, calibration or mask results no longer restarts source decoding.
- The representative-image picker starts with a valid selection and has a clear empty state. Saved model selections keep a matching picker entry.
- The setup sheet stays stable when an import completes, and the preview keeps a fixed height.

## First-use model setup

- Cellpose 3 and 4 show model-loading stages and weight-download progress. Closing a partial download no longer reports success.
- Stalled downloads time out after 30 seconds without data. Slow downloads that keep receiving data continue.
- Download failures include a retry hint.
- Images without scale metadata explain how to set a known scale for calibrated measurements.

## Update

Download `CellCounter-v1.0.12.zip` and its `.sha256` checksum from the [v1.0.12 release](https://github.com/Alperen-Gur/CellCounter/releases/tag/v1.0.12). Quit the older copy, unzip the download and replace `CellCounting.app` in Applications.

If a session was interrupted during first-use setup, reopen the app and resume its paused job from **Processing**. Keep the app open while weights download; completed weights are reused.
