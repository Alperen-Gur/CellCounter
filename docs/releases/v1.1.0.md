# CellCounter v1.1.0 for macOS

This release adds a microscopy workbench whose graphical interface, command-line interface, Python SDK and scoped MCP server use the same saved operations and project revisions.

Requires **macOS 15 or later**. The application is universal for Intel and Apple Silicon, **ad-hoc signed and not notarized**.

## Changes

- Import, segment, correct exact masks, measure and export within portable projects. Corrections retain history, and saved results expose stale inputs and explicit recomputation plans.
- Save linear or branching workflows, review checkpoints, parameter sweeps and resumable background batches. Distributed work uses explicit portable task bundles and isolated result collection.
- Inspect calibrated volumes and time points, linked orthogonal slices, multichannel displays, annotations, tracking and lineage records. Display previews remain separate from scientific source data.
- Organize experiments and biological specimens, run supported assays and statistical analyses, and retain reference datasets, registered local models and model comparison records.
- Browse bounded regions of TIFF, supported OME-Zarr stores and configured OMERO sources. Indexed project storage and paged measurements avoid loading an entire library into the interface.
- Reuse shared workspace engines for layers, semantic painting, vectors and animation. Existing libraries can be captured read-only and migrated through a previewed, checkpointed import; original records and evidence are preserved.
- Configure AI-agent access from the Workbench. The installed executable supports `--workbench` CLI and MCP startup without opening the graphical application. Read, write, external-path and executable-code grants remain explicit.

## Installation and limits

Download `CellCounter-v1.1.0.zip` and its `.sha256` file. Quit the old app and replace **CellCounting.app** in Applications. Existing libraries and model environments are retained. Use **Install or repair runtime** in the Workbench to prepare its dedicated Python environment; learned models and the isolated OMERO interpreter require their own explicit local configuration. See the [installation guide](https://github.com/Alperen-Gur/CellCounter/blob/v1.1.0/docs/INSTALL.md).

Volume display is bounded to 128 voxels per axis; scientific volume operations have separate documented limits. Large-data and remote import controls operate on explicit supported arrays, selections and regions. They do not imply unrestricted whole-slide, whole-server or model-format support. Restored executable plugins and models require explicit local trust and runtime binding. This release does not claim complete parity with every microscopy application or establish comparative biological accuracy.

## Validation

Nonvisual native testing initially passed 143 of 145 tests. Both failures were corrected, and all 34 affected tests passed on rerun. The MCP transport and permission regression suite passed all 14 tests, including external-source grants for transitive recomputation. Release packaging checks cover the universal executable, version, nested runtime manifests, ad-hoc signature, packaged licenses and checksum.

Interactive application validation, visual verification and learned-model or biological-accuracy evaluations were not performed for this release.

Windows is released separately as v1.3.0. The browser preview is v0.3.2 and retains its documented capability limits.
