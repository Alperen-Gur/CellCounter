# CellCounter v1.1.0 for macOS

This release adds a microscopy workbench whose graphical interface, command-line interface, Python SDK and scoped MCP server use the same saved operations and project revisions.

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized.

## Changes

- Import, segment, correct exact masks, measure and export within portable projects. Corrections keep their history, and saved results show stale inputs with a recomputation plan.
- Save linear or branching workflows, review checkpoints, parameter sweeps and resumable background batches. Distributed work uses portable task bundles and separate result collection.
- Inspect calibrated volumes and time points, linked orthogonal slices, multichannel displays, annotations, tracking and lineage records. Display previews stay separate from source data.
- Organize experiments and biological specimens, run assays and statistical analyses, and keep reference datasets, registered local models and model comparisons.
- Browse regions of TIFF, OME-Zarr and configured OMERO sources. Indexed project storage and paged measurement tables load only what is shown.
- Use the shared workspace engine for layers, semantic painting, vectors and animation. Copy an existing library into a project through a previewed, resumable import; the original library is kept.
- Configure AI-agent access from the Workbench. The installed executable starts the `--workbench` CLI and MCP server without opening the graphical app. Read, write, external-path and executable-code access are granted separately.

## Update

Download `CellCounter-v1.1.0.zip` and its `.sha256` file. Quit the old app and replace **CellCounting.app** in Applications. Existing libraries and model environments are kept. In the Workbench, open **AI agent and command-line access** and choose **Install or repair** to set up its Python environment; learned models and the OMERO interpreter are configured separately. See the [installation guide](https://github.com/Alperen-Gur/Cellographer/blob/v1.1.0/docs/INSTALL.md).

The volume display shows up to 128 voxels per axis. Enable restored plugins and models locally before running them.

Windows 1.3.0 and Web 0.3.2 are released separately.
