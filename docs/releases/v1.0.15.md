# CellCounter v1.0.15 for macOS

This release adds fixes and controls for the three open reports: [Review Queue crashes (#10)](https://github.com/Alperen-Gur/CellCounter/issues/10), [slow analyzed-image navigation (#11)](https://github.com/Alperen-Gur/CellCounter/issues/11), and [segmentation of elongated or complex cells (#12)](https://github.com/Alperen-Gur/CellCounter/issues/12).

Requires **macOS 15 or later**. The download is a **universal Intel and Apple Silicon application**, **ad-hoc signed and not notarized**. See the [installation guide](https://github.com/Alperen-Gur/CellCounter/blob/v1.0.15/docs/INSTALL.md).

## Review and library preservation

- Guard review records retained after deletion or reanalysis before reading their saved fields.
- Handle extreme or malformed saved measurements without unsafe integer conversion or invalid preview geometry.
- Clear orphaned analysis records as part of an explicitly requested data reset, while retaining presets and model configuration.
- Remove an obsolete startup migration that could delete a library when its preferences flag was missing. Normal app startup and upgrades preserve the existing library.

## Navigation between analyzed images

- Prepare bounded, decoded display previews away from the interface thread.
- Prepare contour indexes in the background and discard results that belong to an image or revision that is no longer displayed.
- Show unreadable measurement data as a load error, with a retry action and editing disabled, instead of treating it as an empty analysis.
- Preserve original analysis images, measurement data and export resolution. Preview scaling is for display only.

## Controls for elongated and complex cells

Open **Models → Omnipose** to configure the mask threshold, flow error threshold and clustering defaults. Individual jobs expose the same controls under **Set up analysis → Omnipose reconstruction**. These settings travel with saved jobs and protocols, so subsequent analyses can use the same configuration. Unsupported settings fail explicitly instead of silently switching to a different model or dropping required reconstruction options. See the [Omnipose settings documentation](https://omnipose.readthedocs.io/settings.html) for parameter guidance.

Existing Omnipose checkpoint files can be reused in the engine's separate cache. Split-touching reruns preserve same-model saved settings and discard results if the image or its measurements changed during the operation.

These controls provide additional ways to tune an existing segmentation engine. They do not establish improved precision for fibroblasts or neurons. Compare masks against representative labeled images before using a configuration for quantitative work.

## Build and validation status

The production archive was built for both Intel and Apple Silicon. Packaging checks cover the app version, architectures, signature, archive contents and download checksum.

**Automated tests, interactive app validation, navigation benchmarks and segmentation accuracy evaluations were not run for this release.** Regression cases are included in source. The reporter's exact crash and workstation behavior remain unconfirmed.

## Download and update

Download `CellCounter-v1.0.15.zip` and its `.sha256` file from this release. Quit the old application, unzip the download, and replace **CellCounting.app** in Applications. A library reset is not required.

This release publishes only the macOS application. Windows remains v1.1.1 and the web preview remains v0.2.1.
