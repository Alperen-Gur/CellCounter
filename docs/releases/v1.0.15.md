# CellCounter v1.0.15 for macOS

This release fixes the three open reports: [Review Queue crashes (#10)](https://github.com/Alperen-Gur/CellCounter/issues/10), [slow analyzed-image navigation (#11)](https://github.com/Alperen-Gur/CellCounter/issues/11) and [segmentation of elongated or complex cells (#12)](https://github.com/Alperen-Gur/CellCounter/issues/12).

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized. See the [installation guide](https://github.com/Alperen-Gur/CellCounter/blob/v1.0.15/docs/INSTALL.md).

## Review and library preservation

- Check review records kept after deletion or reanalysis before reading their saved fields.
- Handle extreme or malformed saved measurements without unsafe integer conversion or invalid preview geometry.
- Clear orphaned analysis records as part of a requested data reset, while keeping presets and model configuration.
- Remove an obsolete startup migration that could delete a library when its preferences flag was missing. Normal startup and upgrades preserve the existing library.

## Navigation between analyzed images

- Prepare bounded, decoded display previews away from the interface thread.
- Prepare contour indexes in the background and discard results for an image or revision that is no longer displayed.
- Show unreadable measurement data as a load error, with a retry action and editing disabled, instead of an empty analysis.
- Keep original analysis images, measurement data and export resolution unchanged. Preview scaling is for display only.

## Controls for elongated and complex cells

Open **Models → Omnipose** to configure the mask threshold, flow error threshold and clustering defaults. Individual jobs expose the same controls under **Set up analysis → Omnipose reconstruction**. These settings travel with saved jobs and protocols, so later analyses use the same configuration. Unsupported settings report an error instead of switching to a different model or dropping reconstruction options. See the [Omnipose settings documentation](https://omnipose.readthedocs.io/settings.html) for parameter guidance.

Existing Omnipose checkpoint files can be reused in the engine's separate cache. Split-touching reruns keep same-model saved settings and discard results if the image or its measurements changed during the operation.

Compare masks on representative labelled images before relying on a configuration for quantitative work.

## Update

Download `CellCounter-v1.0.15.zip` and its `.sha256` file from this release. Quit the old application, unzip the download and replace **CellCounting.app** in Applications. A library reset is not required.
