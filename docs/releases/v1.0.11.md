# CellCounter v1.0.11 for macOS

This release lets you import and inspect images before installing a segmentation model, preview analysis settings on a representative image, and review completed results while the rest of a batch processes.

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized. See the [installation guide](../INSTALL.md) for first-launch instructions.

## Import, preview and processing

- Import images or folders into a saved analysis setup. Choose the model, calibration, channels, Z projection and preprocessing before running the batch, or import images for inspection without segmentation.
- Preview a whole representative image with an installed model. Matching preview results are reused when the batch starts.
- Start from task presets for cell counts and sizes, nuclei, marker positivity or wound closure. Marker and wound measurements run in their assay panels.
- Processing jobs are saved locally with their settings, progress and per-image failures. Pause after the current image, resume, retry failures, or open completed images while processing continues. Interrupted jobs return as paused after relaunch.
- Saved run settings record the settings that produced a result, separately from later changes to application defaults.

## Review and navigation

- Linked measurement rows, area/intensity plots and image overlays share cell selection, so unusual measurements are easy to inspect.
- Compare saved and current mask variants side by side with synchronized pan and zoom, highlighted changes and a differences-only view.
- Analysis state indicators show processing, saved settings and when a rerun is needed.
- Contextual menus connect search, selection, export, image navigation, zoom, review, training and processing shortcuts to the visible screen. Text fields keep native selection and undo.
- **Help → Keyboard Shortcuts** (`⌘/`) and Settings share the shortcut reference. `⌘O` opens images, `⌘⇧O` opens a folder, and `⌘⌥1` through `⌘⌥9` navigate the primary screens.
- A new microscopy app icon.

## Models and responsiveness

- The Models screen uses cached installation state and background probes, so slow or failed probes no longer block navigation.
- Dense mask overlays use spatial indexing and draw only the visible region. Measurement and summary updates avoid unnecessary decoding and recomputation.
- Assay workers stay warm between compatible requests, with bounded caches for prepared images and masks.
- Processing overlaps image preparation when memory permits. Model execution and training share an execution guard so they do not compete for memory.

## Local fine-tuning

Fine-tuning now trains on reviewed library masks and reports a held-out evaluation. The annotation view shows the source image and corrected boundaries; saved mask edits become the training labels.

Training uses an installed **Cellpose 3.x** environment and compatible base weights. Select at least three independent specimen groups, review every selected field, and keep related fields or crops in the same group. Deterministic train/validation/test splits keep groups separate and reject duplicate source files. Validation selects the checkpoint; test images are reserved for the final report.

Only a checkpoint with a completed evaluation report can be saved to Models. Reports include AP at IoU 0.5, precision, recall, F1 and mean diameter error in source pixels. Training uses full precision and at least six epochs. Fine-tuning covers Cellpose 3; Cellpose 4/SAM, StarDist and Omnipose are not included.
