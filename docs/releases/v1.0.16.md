# CellCounter v1.0.16 for macOS

This maintenance release improves data integrity, editing, model reproducibility and workspace operations, and removes unused code.

Requires **macOS 15 or later**. The application is universal for Intel and Apple Silicon, **ad-hoc signed and not notarized**.

## Changes

- Commit library deletions before removing image files, report failed saves, and remove associated review and annotation records together.
- Keep Results edits attached to the current detection revision and preserve pending corrections when composing toolbar and sequence edits.
- Apply current batch calibration to new measurements and keep review/export scale bars physically accurate.
- Save ensemble member IDs in protocols and restore the intended pair. Older protocols explicitly warn when their original pair is unknown.
- Retire affected warm detector processes when their Python runtime changes, including failed reinstalls. Keep Cellpose 3 and Cellpose 4 retirement separate.
- Use the actual Cellpose denoising model for restoration and preserve pinned NumPy compatibility during optional reader installation.
- Reject unsafe OME-Zarr and animation arithmetic, improve cancellation handling, and discard late workspace results.
- Remove unused views, helpers and duplicate installer logic.

## Installation and validation

Download `CellCounter-v1.0.16.zip` and its `.sha256` file. Quit the old app and replace **CellCounting.app** in Applications. Existing library data and model environments are retained; no reset is required. Follow the [installation guide](https://github.com/Alperen-Gur/CellCounter/blob/v1.0.16/docs/INSTALL.md) for Gatekeeper handling.

The release receives production compilation for both architectures and checks of bundle version, signature, packaged contents and checksum. **Automated tests, interactive application validation and biological-accuracy evaluations were not run.** Runtime resolution of the reported failures remains unconfirmed.

Windows is released separately as v1.1.2. The web preview remains v0.2.1.
