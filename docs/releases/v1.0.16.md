# CellCounter v1.0.16 for macOS

This maintenance release improves data integrity, editing, model reproducibility and workspace operations, and removes unused code.

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized.

## Changes

- Commit library deletions before removing image files, report failed saves, and remove associated review and annotation records together.
- Keep Results edits attached to the current detection revision and preserve pending corrections when combining toolbar and sequence edits.
- Apply the current batch calibration to new measurements and keep review/export scale bars physically accurate.
- Save ensemble member IDs in protocols and restore the intended pair. Older protocols warn when their original pair is unknown.
- Retire affected warm detector processes when their Python runtime changes, including failed reinstalls. Keep Cellpose 3 and Cellpose 4 retirement separate.
- Use the actual Cellpose denoising model for restoration and keep pinned NumPy compatibility during optional reader installation.
- Reject unsafe OME-Zarr and animation arithmetic, improve cancellation handling, and discard late workspace results.
- Remove unused views, helpers and duplicate installer logic.

## Update

Download `CellCounter-v1.0.16.zip` and its `.sha256` file. Quit the old app and replace **CellCounting.app** in Applications. Existing library data and model environments are kept; no reset is required. Follow the [installation guide](https://github.com/Alperen-Gur/Cellographer/blob/v1.0.16/docs/INSTALL.md) if macOS blocks the first launch.

Windows is released separately as v1.1.2.
