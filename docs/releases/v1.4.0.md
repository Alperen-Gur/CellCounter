# Cellographer v1.4.0 for macOS

CellCounter is now called Cellographer. This release changes the name only.

Requires **macOS 15 or later on Apple silicon**. Ad-hoc signed and not notarized.

## New name

- The app is now **Cellographer.app**.
- The repository is now [github.com/Alperen-Gur/Cellographer](https://github.com/Alperen-Gur/Cellographer).
  Old links to CellCounter redirect there.
- The download is `Cellographer-v1.4.0.zip`, with its `.sha256` file.

## Nothing else changes

- The features are the same as in 1.3.0.
- Cellographer uses the same data as CellCounter, so your libraries, settings, models and Python
  environments are kept.

## Windows and browser apps

The Windows and browser apps keep the CellCounter name until their next release.

## Citing

When you cite the software, use the new name, Cellographer. See
[CITATION.cff](https://github.com/Alperen-Gur/Cellographer/blob/v1.4.0/CITATION.cff).

## Update

Download `Cellographer-v1.4.0.zip` and its `.sha256` file. Quit CellCounter, unzip the download
and move **Cellographer.app** to Applications, then delete **CellCounting.app**. Both apps open
the same libraries, so don't keep both. See
[Install](https://github.com/Alperen-Gur/Cellographer/blob/v1.4.0/docs/INSTALL.md#install).

If you connected an AI agent through MCP, copy the new configuration from **AI agent and command-line access**:
the old one starts `CellCounting.app` and stops working once that app is deleted.
