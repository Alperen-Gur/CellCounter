# CellCounter v1.0.14 for macOS

This patch adds further fixes for the Review Queue failures reported in [issue #10](https://github.com/Alperen-Gur/CellCounter/issues/10), following the earlier large-library improvements in v1.0.13.

Requires **macOS 15 or later**. The download is a **universal Intel and Apple Silicon application**, **ad-hoc signed and not notarized**. See the [installation guide](https://github.com/Alperen-Gur/CellCounter/blob/v1.0.14/docs/INSTALL.md).

## Review and save reliability

- Repair stale review entries left behind by older deletion or reset behavior, while preserving live detections and corrections.
- Guard background work against records deleted during decoding, editing, or reanalysis. Serialize image and contour decoding to limit overlapping work.
- Save review decisions and undo before advancing the queue. Show read, decoding, encoding, and save failures explicitly.
- Finish pending Results edits before review decisions, and prevent delayed edits from overwriting a newer analysis.
- Recount pending candidates after changes so delayed notifications cannot recreate an outdated review badge.
- Refresh review measurements after recalibration and defer review decisions until calibration updates finish.
- Handle invalid measurements and submicron diameter-edit ranges without unsafe drawing or inverted slider bounds.

## Preview reliability

- Recover missing or damaged thumbnails from a bounded preview of the imported image.
- Decode thumbnails before rendering, with a maximum image size, rather than deferring file decoding to the interface.
- Preserve the raw pixel orientation used by detections when displaying review previews.
- Keep thumbnails at least one pixel wide and high, including very thin images.

## Build and validation status

The production archive was compiled for both Intel and Apple Silicon. Packaging checks cover the app's version, architectures, signature, archive contents, and download checksum.

Automated regression tests and interactive app validation were **not run for this release**. Additional regression cases are included in source. The reporter's exact crash has not been reproduced or confirmed resolved with their original library and crash report.

## Download and update

Download `CellCounter-v1.0.14.zip` and `CellCounter-v1.0.14.zip.sha256` from the [macOS release](https://github.com/Alperen-Gur/CellCounter/releases/tag/v1.0.14). Quit the old application, unzip the download, and replace **CellCounting.app** in Applications. Existing images and corrections are preserved; a library reset is not required.

This release uses ad-hoc signing and is not notarized. Follow the installation guide if macOS blocks the first launch.

Windows image-display fixes are also committed in source, but this release publishes only the macOS application. The existing Windows v1.1.0 installers are unchanged.
