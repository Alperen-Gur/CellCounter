# CellCounter v1.0.13 for macOS

This release fixes [issue #9](https://github.com/Alperen-Gur/CellCounter/issues/9): instability when opening large Review Queues after processing hundreds of images.

Requires **macOS 15 or later**. Universal app for Intel and Apple Silicon, ad-hoc signed and not notarized. See the [installation guide](../INSTALL.md).

## Review large batches

- Decoded cell contours share a bounded cache instead of accumulating on every saved detection.
- Review loads stable pages of up to 96 candidates. Cells with equal confidence keep a consistent order, and Skip continues through every page.
- Keep, Reject, Resize and undo are saved across page boundaries. Background saves cannot overwrite a newer correction.
- Previews follow the current card and render at card size instead of building full-image overlays for every candidate.
- Libraries that need a review-key migration complete it before the queue opens.

## Update

Download `CellCounter-v1.0.13.zip` and its `.sha256` checksum from the [macOS v1.0.13 release](https://github.com/Alperen-Gur/CellCounter/releases/tag/v1.0.13). Quit the old copy, unzip the download and replace `CellCounting.app` in Applications, then reopen **Review Queue**. Existing images, detections and corrections are preserved; no library reset is needed.

Windows 1.1.0 and Web 0.2.1 are released separately; see the [platform comparison](../PLATFORM-PARITY.md).
