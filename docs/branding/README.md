# CellCounter app icon

`CellCounter-icon.png` is the 1024 × 1024 RGBA master. The ten 16–1024 pixel macOS
variants are installed in `CellCounting/Assets.xcassets/AppIcon.appiconset/`.
Xcode compiles that catalog into the application icon. The three pale cells,
segmentation outlines, and deep teal tile are designed to remain legible in the Dock.

Created with the built-in image-generation tool, then exported with a transparent
exterior matte and resized for the macOS catalog. No stock image was used.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for CellCounter, a
professional microscopy cell-counting and measurement app. Create a single beautifully
crafted icon, 1024 by 1024 pixels. A deep teal rounded-square tile centered with a narrow
transparent margin, subtle premium depth and soft corner highlights. Inside: three
distinct luminous ivory/mint organic cells with small dark teal nuclei, arranged as a
simple asymmetrical cluster. Precise thin segmentation outlines around the cells
suggest measured microscope masks. The three-cell silhouette must remain clear at
32px; generous spacing, restrained detail. Calm scientific instrument aesthetic,
original memorable visual mark, superb optical balance. Soft studio lighting with very
restrained material depth; modern and professional, neither cartoon nor realistic
tissue. No text, letters, numerals, microscope illustration, app screenshots,
watermarks, mockup device, or extraneous objects. Single finished square icon asset
only, genuinely transparent outside the rounded tile. Keep all cell shapes inside a
safe central area so they read clearly in the macOS Dock.

## Selected refinement prompt

Refine this CellCounter macOS app icon into a more restrained professional scientific
software icon. Preserve its deep teal rounded square tile, transparency outside the
tile, and the exact three-cell arrangement and dark teal nuclei. Simplify ONLY the
rendering/material style: remove microscopic speckle, bubbles, organelle clutter,
mottled textures and photographic realism. Render each cell as a smooth ivory/mint
softly sculpted shape with a clean dark teal nucleus, extremely subtle shading, and a
crisp precise segmentation outline with just a few small selection nodes. Reduce
bright glass rim highlights and background blobs, use an elegant nearly uniform deep
teal background with a very subtle gradient. Aim for an exceptionally clear silhouette
at 16 and 32 pixels, tasteful native macOS icon polish, high contrast, generous breathing
room, no text, no new objects.
