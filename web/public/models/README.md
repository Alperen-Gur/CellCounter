# Web model assets

Place browser model artifacts here for local WebGPU inference. Each artifact
needs a versioned catalog entry, checkpoint identity, SHA-256 and byte length.
See the [model build instructions](../../src/models/BUILD-CONTRACT.md).

For segmentation without model files, choose **Classical threshold + watershed**.
It runs locally in a browser Worker.

See the [browser guide](../../../docs/WEB.md) or
[desktop downloads](../../../README.md#download).
